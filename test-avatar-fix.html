Test Avatar Reset for Premium Users

This test verifies that premium users can reset their avatar to default by submitting an empty string.

Test Cases:

  1. Premium user submits empty avatar URL → Should revert to "/default-avatar.png"
  2. Premium user submits valid avatar URL → Should update to new URL
  3. Non-premium user submits avatar URL → Should return error

Expected Behavior:

When a premium user clears the avatar URL field and saves, the backend should set avatarUrl to "/default-avatar.png" instead of keeping the old value.

Fix Applied:

  • Changed condition from updates.avatarUrl && isPremium to typeof updates.avatarUrl !== 'undefined' && isPremium
  • Added explicit check for empty string: if (!urlStr) { avatarUrl = "/default-avatar.png"; }
  • Updated else condition to also use typeof updates.avatarUrl !== 'undefined'
